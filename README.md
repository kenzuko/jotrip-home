# Open Phu Quoc Home

Public information platform for Phu Quoc.

## Locked direction

- Product principle: utility first, editorial second
- Visual direction: quiet localism
- Brand: Open Phu Quoc - Modern Minimal B
- Local materials: fishing-boat eye, Melo pearl, mother-of-pearl, boat wood and island textures
- Core palette: Sea Ink, Melo Orange, Pearl Ivory
- Avoid: generic travel portal, resort brochure, excessive luxury styling, decorative local motifs over live information

## V1 homepage

1. Search
2. Phu Quoc Today
3. Getting Around
4. Explore Phu Quoc
5. Guide
6. Local Notes
7. Data sources / maintained by JoTrip

Mobile-first. Live modules will later connect Airport, Weather & Sea, Ferry, Bus and other transport feeds.
