## Cách sửa

Sửa trực tiếp phần chữ đọc được. Giữ nguyên các dòng comment `STORY_ID`, `SECTION` và `TOPIC_ID` để sau khi duyệt có thể map ngược vào JSON chính xác.

Các file Knowledge chỉ chứa phần editorial/public để đọc nhanh; research, sources và operational data vẫn nằm nguyên trong JSON nguồn và không bị đưa vào vòng sửa văn.
