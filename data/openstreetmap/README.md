# Near Me OpenStreetMap candidates

This file contains a separate community-mapped reference layer for Near Me. It is not merged into the canonical location index.

- Database license: [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/)
- Attribution: [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright)
- Every record is an unverified candidate with unknown current operating status.
- Near Me presents these records separately, does not treat them as official directory entries, and does not rank them by GPS or include them in distance-radius counts.
- The map links let guests inspect a candidate location. Confirm the business and its entrance before relying on the pin.

Update this layer only with OSM source references, attribution, and license metadata intact. Move a record into the canonical directory only after independent source verification and review of its location provenance.
